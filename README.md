# Welcome to the Rayfin & Foundry Hackathon

## Overview

Use an AI coding agent to turn the included Northwind procurement spend workbook into an interactive Microsoft Fabric app with Rayfin. Explore spend across business units, categories, and suppliers, and identify illustrative savings opportunities.

Then build a Microsoft Foundry Spend Copilot that answers questions using your Fabric semantic model and connect it to the app. Finally, add a Savings Opportunity Tracker so users can save and update opportunities that only they can read and edit.

The exercises guide you from **Excel data -> Fabric semantic model -> interactive app -> AI assistant -> writeback**, with prompts and checks at each stage.

## Let's get started

1. **[Setup Tooling](docs/setup/README.md)** - Prepare your local, Fabric, and Foundry tools.
2. **[Build our App](docs/build-app/README.md)** - Create a semantic model in Fabric, build the app, and refine a visualization.
3. **[Build a Foundry Agent](docs/foundry-agent/README.md)** - Create and test an agent, then connect it to your Fabric app.
4. **[Update our App](docs/update-app/README.md)** - Add writeback to the app.
