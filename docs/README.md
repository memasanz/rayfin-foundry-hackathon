# Hackathon documentation

Start with **Setup Tooling**, then follow the exercises in order:

1. **[Setup Tooling](setup/README.md)** - Prepare your local, Fabric, and Foundry tools.
2. **[Build our App](build-app/README.md)** - Create the semantic model, build the app, and refine a visualization.
3. **[Build a Foundry Agent](foundry-agent/README.md)** - Create and test your Spend Copilot, then connect it to the app.
4. **[Update our App](update-app/README.md)** - Add a Savings Opportunity Tracker with creator-only access.

Looking for a specific tool? See the [installation guides](install/README.md).
